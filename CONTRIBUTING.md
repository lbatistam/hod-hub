# Contribuindo

1. Abra uma issue descrevendo comportamento atual, esperado e evidência.
2. Crie uma branch curta e focada.
3. Preserve as regras documentadas em `docs/business-rules.md`.
4. Rode validações de frontend e API.
5. Abra um pull request com escopo, impacto e resultados dos testes.

Não inclua dados reais de clientes, bancos SQLite, logs, credenciais ou screenshots sem anonimização.
